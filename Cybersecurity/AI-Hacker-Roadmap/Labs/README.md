# Labs

这里记录仅在合法授权环境中完成的实验。

建议每个实验包含：

- 实验名称
- 平台
- 日期
- 漏洞类型
- 自己的分析
- 验证步骤
- 截图
- 修复建议

不要记录真实用户数据、账号凭证或不在授权范围内的信息。

- `ClientControls/`：Day 5 客户端隐藏参数实验。
- `EchoServer/`：Day 2 外部回显服务不可用时的本地备用服务。
- `SQLBasics/`：Day 8 SQLite 参数化查询实验。
- `XSSBasics/`：Day 10 HTML 输出上下文实验。
- `LocalHTTP/`：Day 18–21 本地 HTTP 工具实验。
- `CodeReview/`：Day 23–25 AI 辅助代码审查实验。
