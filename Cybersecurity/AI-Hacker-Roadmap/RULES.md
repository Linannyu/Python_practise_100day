# Training Rules

## 规则 1：每天最低只要求 10 分钟

完成核心任务就算当天成功。不要因为没有一小时空闲就完全不开始。

## 规则 2：先做，再补理论

先看到请求、响应和实验结果，再学习当天真正需要的概念。

## 规则 3：不提前收藏大量教程

当天只使用完成任务需要的资源，避免收藏很多但没有执行。

## 规则 4：AI 必须解释原因

不要只问 AI：“给我答案。”

更好的问题：

- 这段请求每一部分是什么意思？
- 服务器为什么返回这个结果？
- 我的判断可能错在哪里？
- 怎样在授权环境中验证这个假设？
- 请先给提示，不要直接给最终答案。

## 规则 5：所有测试必须经过授权

允许：

- 本地 Docker 靶场
- 官方安全实验平台
- 明确列出测试范围的 Bug Bounty 项目

不允许：

- 随机扫描真实网站
- 尝试进入他人账号
- 测试学校、公司或公共系统
- 在未授权目标上使用攻击载荷

## 规则 6：每天留下证据

至少留下一个：

- Markdown 记录
- 截图
- Git commit
- 代码文件
- 实验结果

## 规则 7：卡住 10 分钟就记录问题

写下：

1. 我想完成什么？
2. 我做了什么？
3. 实际发生了什么？
4. 我原本期待什么？
5. 报错或截图是什么？
