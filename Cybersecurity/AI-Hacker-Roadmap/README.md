# AI Hacker Roadmap

> 从零开始学习 Web 安全、AI 辅助分析与合法漏洞研究。

## 30 天目标

- 学会使用 Burp Suite 抓取、查看和修改 HTTP 请求。
- 理解常见 Web 漏洞的基础原理。
- 在合法靶场中完成基础漏洞实验。
- 使用 Python 编写简单的安全辅助工具。
- 学会使用 AI 解释请求、分析代码和提出测试思路。
- 建立可用于大学申请展示的网络安全学习项目。

## 长期目标

- 学习红队与渗透测试基础。
- 参加合法、明确授权的 Bug Bounty 项目。
- 建立网络安全作品集。
- 为大学计算机科学或网络安全方向申请积累经历。

## 学习方式

每天最低完成一个 **10 分钟核心任务**。

状态好时继续完成扩展挑战；状态不好时，只完成核心任务也算成功。

每天至少留下一个成果：

- 实验记录
- 截图
- Git commit
- 小脚本
- 自己写下的解释

## 安全边界

本项目中的测试只用于：

- 自己搭建的环境
- PortSwigger Web Security Academy
- OWASP Juice Shop
- DVWA
- 明确授权且在范围内的 Bug Bounty 项目

不要测试没有授权的网站、账号、设备或网络。
