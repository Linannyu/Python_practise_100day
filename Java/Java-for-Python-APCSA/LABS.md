# Daily Lab Roadmap

Each course day has one substantial implementation goal. A later Lab deliberately reuses earlier Java skills and introduces the current chapter’s concept, so you learn to combine ideas rather than solve isolated syntax prompts.

| Day | Lab | New focus | Reuses |
|---|---|---|---|
| 01 | [Java Study Card](./01-Basics/practice.md) | class, `main`, output | Python print mental model |
| 02 | [Study Session Receipt](./02-Variables-DataTypes/practice.md) | types, arithmetic | output and structure |
| 03 | [Course Readiness Checker](./03-Conditionals/practice.md) | boolean logic, if | typed data and output |
| 04 | [Study Week Analyzer](./04-Loops/practice.md) | loops | arrays, conditions, arithmetic |
| 05 | [Study Toolkit](./05-Methods/practice.md) | methods | loops and arrays |
| 06 | [Username Inspector](./06-String/practice.md) | String methods | methods, loops, boolean logic |
| 07 | [Score Analyzer](./07-Arrays/practice.md) | array traversal | methods and thresholds |
| 08 | [Flexible Study Planner](./08-ArrayList/practice.md) | ArrayList | String comparison and safe loops |
| 09 | [StudyTask Object](./09-Classes-Objects/practice.md) | classes/objects | ArrayList and reports |
| 10 | [Specialized Study Tasks](./10-Inheritance/practice.md) | inheritance | class design and polymorphism |
| 11 | [Weekly Focus Grid](./11-2D-Arrays/practice.md) | 2D arrays | methods and nested loops |
| 12 | [Recursive Streak Explorer](./12-Recursion/practice.md) | recursion | array contracts and edge cases |
| 13 | [AP CSA Study Dashboard](./13-APCSA-Review/practice.md) | integration / FRQ style | all core AP CSA skills |

## Daily workflow

```text
Read lesson → write the Lab → compile → test required cases
→ record a mistake if needed → use drills only to target a weak skill
```

The original 15-question sets are preserved as `drills.md` inside every chapter. Use them as a short warm-up, a repair exercise after a failed Lab test, or optional extra practice—not as a replacement for building the daily Lab.
