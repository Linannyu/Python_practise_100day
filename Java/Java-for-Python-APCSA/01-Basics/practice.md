# Chapter 01 Practice — Basics

先在 `work/01-Basics/<problem-id>/Main.java` 写程序。每个完整程序使用 `public class Main` 和 `main`。完成后再查看 [solutions.md](./solutions.md)。

## Level 1 — 5 problems

## Problem 01-01 🟢 Beginner — First line
写完整 Java 程序，恰好打印 `Hello, Lin!` 一行。

## Problem 01-02 🟢 Beginner — Two prints
打印 `Java` 与 `AP CSA`，每个各占一行。

## Problem 01-03 🟢 Beginner — One line together
只用两个 `System.out.print` 调用输出一行 `Python -> Java`，最后换行。

## Problem 01-04 🟢 Beginner — Commented plan
写完整程序，包含一条 `//` 注释说明输出目的，并打印 `Ready`。

## Problem 01-05 🟢 Beginner — Block comment
写完整程序，含一个 `/* ... */` 多行注释，并打印你的名字和 `is learning Java.`。

## Level 2 — 5 problems

## Problem 01-06 🟡 Intermediate — Mini schedule
打印三行：`1. Read`、`2. Code`、`3. Test`。每行使用独立 `println`。

## Problem 01-07 🟡 Intermediate — Exact shape
打印下列两行，不多空格：
```text
***
* *
```

## Problem 01-08 🟡 Intermediate — Print versus println
用一次 `print` 和一次 `println` 产生恰好一行 `AP CSA`。

## Problem 01-09 🟡 Intermediate — Compile vocabulary
打印四行：`Source: .java`、`Compiler: javac`、`Bytecode: .class`、`Runtime: JVM`。

## Problem 01-10 🟡 Intermediate — Fix it by writing it
从空文件写出能编译、并打印 `Braces and semicolons matter.` 的最小 `Main.java`。

## Level 3 — 3 problems

## Problem 01-11 🔴 Advanced — Console card
打印一张三行文本卡片：第一行是你的名字，第二行 `Python programmer`，第三行 `Future AP CSA student`。不得使用变量（本章只练结构）。

## Problem 01-12 🔴 Advanced — Escape quote
打印 `She said "Java is precise."`。研究 Java 字符串如何显示双引号。

## Problem 01-13 🔴 Advanced — Backslash
打印 Windows 风格路径 `C:\Java\Main.java`。确保输出中每个反斜杠只出现一次。

## AP CSA Style — 2 problems

## Problem 01-14 ⭐ AP CSA — Trace formatting
不运行程序，预测下面的精确输出；然后自己写相同程序验证。
```java
System.out.print("A");
System.out.println("B");
System.out.println("C");
```

## Problem 01-15 ⭐ AP CSA — Diagnose
给出下面代码的**第一个**编译问题，并写出修正后的完整程序：
```java
public class Main {
    public static void main(String[] args) {
        System.out.println("Start")
    }
}
```
